# Secure Login System 🔐

A simple secure login web application built using Flask.

## Features
- User registration
- Secure login system
- Password hashing using bcrypt
- Session management
- Logout functionality
- SQLite database integration

##  Technologies Used
- Python
- Flask
- SQLite
- bcrypt

##  Security Features
- Passwords are hashed (not stored in plain text)
- Basic login attempt protection
- Session-based authentication

##  How to Run

```bash
pip install -r requirements.txt
python app.py
